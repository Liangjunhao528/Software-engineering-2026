# 小学四则运算题目生成器

一个 Python 命令行工具，可以生成小学四则运算题目并批改答案。

## 环境要求

- Python 3.6+
- 无需安装第三方库

## 使用方法

### 生成题目

```bash
python3 myapp.py -n 10 -r 10
```

- `-n`：题目数量
- `-r`：数值范围（题目数值 < r）

生成 `Exercises.txt`（题目）和 `Answers.txt`（答案）。

### 批改

```bash
python3 myapp.py -e Exercises.txt -a Answers.txt
```

生成 `Grade.txt`（批改结果）。

## 示例

`Exercises.txt`：
```
1. 3/5 + 2 = 
2. 7 - 2'1/3 = 
```

`Answers.txt`：
```
1. 2'3/5
2. 4'2/3
```

`Grade.txt`：
```
Correct: 1 (1)
Wrong: 1 (2)
```

## 参数

| 参数 | 含义 |
|------|------|
| `-n` | 题目数量 |
| `-r` | 数值范围 |
| `-e` | 题目文件 |
| `-a` | 答案文件 |
| `-h` | 帮助 |

## 说明

- 支持自然数和真分数（如 `3/5`、`2'3/8`）
- 支持 `+`、`-`、`×`、`÷`
- 保证运算过程不出现负数，除数不为零
- 自动去重
